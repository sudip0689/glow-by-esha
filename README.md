# 💄 Glow By Esha - Professional Makeup Showcase Website

A modern, responsive React-based website showcasing professional makeup artistry services.

## 🌟 Features

- **Home Page**: Beautiful hero section with featured services
- **Portfolio**: Showcase of makeup looks and artistic work
- **About Section**: Information about Esha's experience and expertise
- **Services**: Detailed service offerings with pricing
- **Contact & Booking**: Professional inquiry and booking form
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Modern UI**: Gradient designs, smooth animations, and professional styling

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sudip0689/glow-by-esha.git

# Navigate to project directory
cd glow-by-esha

# Install dependencies
npm install

# Start the development server
npm start
```

The website will open at `http://localhost:3000`

## 📝 Customization

### Update Business Information
- Edit phone number in `Contact.js`
- Update email address
- Modify location and hours
- Add Instagram/social media links

### Add Your Own Images
- Replace emoji placeholders with actual image URLs
- Update portfolio items with real makeup photos
- Customize color scheme in CSS files

### Modify Services & Pricing
- Edit service cards in `Services.js`
- Update pricing information
- Add or remove service offerings

## 📱 Responsive Breakpoints

- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: Below 768px
